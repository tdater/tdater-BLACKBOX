# BLACKBOX

A flight recorder for debugging on Android. Capture logs, photos and voice notes, run tests against
plans that can't quietly change, compare runs without pretending gaps are "the same", and resume from
a one-screen briefing. Built for the Galaxy Z Fold. Everything stays on the phone: no account and no
internet permission.

## Download

**[Get the latest APK](https://github.com/tdater/BLACKBOX-releases/releases/latest)** (under *Assets*).

**[See everything it does](https://tdater.github.io/BLACKBOX-releases/)**

## Install

1. On the phone, download the APK from the latest release.
2. Open it and allow your browser or file manager to install unknown apps when asked.
3. Tap **Install**.

Requires Android 10 or newer.
